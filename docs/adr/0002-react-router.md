# Маршрутизация фронтенда на react-router

Фронтенд — SPA, адреса страниц разбирает клиент, а бекенд на любой неизвестный путь вне `/api` отдаёт `index.html`. Для маршрутов выбран react-router, а не самописный роутер на `history`: впереди страницы с параметрами (идентификатор Типа встречи в ссылке), вложенные разделы Владельца и переходы в тестах, и всё это react-router уже умеет.

## Considered Options

- Самописный роутер: без зависимости, но разбор параметров и тестовую обвязку пришлось бы писать самим, а с ростом числа страниц его всё равно пришлось бы заменить.
