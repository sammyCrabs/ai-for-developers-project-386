## Пользовательский сценарий

Референс: [Cal.com](https://cal.com/). Регистрация, внешние календари и уведомления в сценарий не входят.

Роли:

- **Владелец** — человек, чьё время бронируют. Создаёт типы встреч и смотрит записи.
- **Гость** — человек, который выбирает свободное время и записывается на встречу.

### Владелец: создание типа встречи

1. Владелец открывает раздел «Типы встреч» и нажимает «Новый тип встречи».
2. Заполняет форму: название (например, «Знакомство»), идентификатор для ссылки (`intro`), описание и длительность в минутах (например, 30).
3. Сохраняет форму. Тип встречи появляется в списке, у него есть публичная ссылка на страницу записи.
4. Владелец передаёт ссылку гостю.

### Гость: запись на свободное время

1. Гость открывает публичную страницу и видит доступные типы встреч с названием, описанием и длительностью.
2. Выбирает тип встречи и открывает календарь.
3. Выбирает дату. Приложение показывает свободные слоты этой даты с учётом длительности встречи. Занятые слоты не показываются.
4. Выбирает время слота.
5. Вводит имя, email и, по желанию, комментарий.
6. Подтверждает запись и видит экран подтверждения: тип встречи, дата, время, длительность.

### Владелец: просмотр записей

1. Владелец открывает раздел «Предстоящие встречи».
2. Новая запись есть в списке: тип встречи, дата и время, имя и email гостя.
3. Записи отсортированы по времени начала. Выбранный гостем слот больше не доступен для записи.

### Обязательные функции

- Создание и просмотр типов встреч (название, идентификатор, описание, длительность).
- Публичный список типов встреч для гостя.
- Расчёт свободных слотов на выбранную дату.
- Создание записи на слот с данными гостя.
- Запрет записи на занятый слот: два бронирования не пересекаются по времени.
- Список предстоящих записей владельца.
