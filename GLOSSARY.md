# Календарь звонков

Сервис, через который Гости записываются на звонки с единственным Владельцем в свободное от других записей время.

## Роли

**Владелец**:
Единственный человек, чьё время бронируют. Создаёт Типы встреч и смотрит предстоящие записи.
_Avoid_: Админ, хост, организатор, пользователь

**Гость**:
Человек, который выбирает Тип встречи и свободное время и записывается на звонок с Владельцем.
_Avoid_: Клиент, посетитель, пользователь

## Встречи

**Тип встречи**:
Шаблон звонка, который предлагает Владелец: название, идентификатор для ссылки, описание и длительность в минутах.
_Avoid_: Событие, услуга, event type

**Запись**:
Звонок определённого Типа встречи, на который Гость записался в конкретное время, вместе с данными Гостя.
_Avoid_: Бронирование, встреча, booking

## Страницы

**Главная страница**:
Страница по корневому адресу. Рассказывает Гостю о сервисе, ведёт в Каталог типов встреч, а Владельцу даёт ссылки на его разделы.
_Avoid_: Лендинг, стартовая, домашняя страница

**Каталог типов встреч**:
Публичная страница со списком Типов встреч, с которой Гость начинает запись.
_Avoid_: Страница записи, публичная страница, список встреч
